# CivicShield

**An evidence-based platform for detecting suspicious Indian government e-Challan / RTO communications.**

> ⚠️ **Academic Prototype**: This is a Design Engineering / IDT academic prototype. It is not a certified fraud-detection tool and does not certify the authenticity of any government communication.
>
> **Mandatory Limitation**: CivicShield provides an evidence-based assessment and does not certify the authenticity of a government communication.

---

## Project Purpose

Fraudulent e-Challan messages targeting Indian vehicle owners are common. CivicShield helps citizens evaluate whether a received message, URL, image, or PDF is likely genuine or fraudulent — using transparent, auditable rule-based and classical ML signals.

Every finding is explained in plain language. No black-box scores. No fabricated accuracy claims.

## Setup Instructions

### Prerequisites

- Python 3.10+
- Node.js 18+
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) (for image OCR — optional)

### Backend

```bash
# From project root
cd backend

# Create virtual environment
python -m venv venv
.\venv\Scripts\activate   # Windows
# source venv/bin/activate  # Linux/macOS

# Install dependencies
pip install -r requirements.txt

# Start the server (from project root)
cd ..
python -m uvicorn backend.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`
Swagger docs: `http://localhost:8000/docs`

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at `http://localhost:5173`

## Dataset Information

CivicShield uses the **PhiUSIIL Phishing URL NLP Dataset** for training the URL risk ML model.

- Place the CSV at: `data/PhiUSIIL_Phishing_URL_NLP_Dataset.csv`
- The training script auto-detects the URL and label columns.

**Feature Selection Policy**: Only URL-structural features are used — no webpage fetching at inference time. This is a deliberate security decision to prevent SSRF and ensure the system works without network access. Specifically excluded from the model: page title, meta description, favicon, JavaScript signals, SSL certificate details, page content features.

---

## Model Training Instructions

```bash
# From project root (with venv active)
python scripts/train_url_model.py
```

This will:
1. Load the PhiUSIIL dataset
2. Compute 12 URL-structural features per URL
3. Train a RandomForestClassifier (100 trees, balanced class weights)
4. Save the model to `models/url_risk_model.joblib`
5. Save the test set to `models/test_set.joblib`

### Evaluation

```bash
python scripts/evaluate_model.py
```

Reports accuracy, precision, recall, F1, and confusion matrix on the held-out test split.

> **Important**: Metrics are measured on the PhiUSIIL dataset test split. Real-world performance on Indian e-Challan phishing may differ — the dataset does not specifically target Indian government impersonation.

## Rule Configuration

All detection rules are in human-readable YAML and can be updated without code changes:

- **`rules/url_rules.yaml`**: Official domain whitelist, URL shortener list, suspicious TLD list, brand keywords, typosquat targets, APK patterns
- **`rules/language_rules.yaml`**: e-Challan and scam language patterns with severity levels; verdict thresholds

### Verdict Thresholds (configurable in `rules/language_rules.yaml`)

```yaml
verdict_thresholds:
  fraudulent_high_count: 2          # >= N HIGH signals => Likely Fraudulent
  fraudulent_medium_count: 4        # >= N MEDIUM signals => Likely Fraudulent
  fraudulent_mixed_medium_with_high: 2  # 1 HIGH + >= N MEDIUM => Likely Fraudulent
  genuine_requires_official_domain: true
  genuine_requires_zero_high: true
```

## Limitations

1. **Not certified**: CivicShield provides an evidence-based assessment and does not certify the authenticity of a government communication.
2. **URL analysis only**: URLs are analysed structurally. The system does NOT visit or fetch URLs.
3. **OCR accuracy**: Text extraction from images depends on image quality and Tesseract installation.
4. **Rule coverage**: Rules cover known e-Challan fraud patterns. Novel attack patterns may not be detected.
5. **ML model scope**: The ML model is trained on PhiUSIIL which is a general phishing URL dataset, not specific to Indian government impersonation.
6. **Language**: Currently English only. Hinglish and regional-language messages are not processed.
7. **No webpage analysis**: Page content, SSL certificate details, and WHOIS data are not checked (deferred to P2).

## Security Notes

- Uploaded files are processed entirely in-memory — never written to disk
- PDFs are not executed (PyMuPDF does not evaluate JavaScript)
- APK files are never downloaded or executed
- No user content is sent to external services
- Database stores only SHA-256 hashes of inputs, not raw content
